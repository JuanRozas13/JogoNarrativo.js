# 🧩 Labirinto Alpha

Jogo narrativo de labirinto desenvolvido em **JavaScript + Node.js** utilizando apenas conceitos básicos de lógica de programação.

O projeto foi criado com foco em aprendizado, prática de estruturas fundamentais da programação e desenvolvimento de raciocínio lógico.

---

# 🎮 Sobre o jogo

O jogador precisa sobreviver atravessando um labirinto composto por:

* 5 fases
* 5 portas em cada fase
* monstros escondidos aleatoriamente
* sistema de vidas
* dificuldades progressivas

O objetivo é encontrar portas seguras e sobreviver até o final.

---

# ⚔️ Dificuldades

## 🟢 Fácil

* 2 monstros
* 3 portas seguras

---

## 🟡 Intermediário

* 3 monstros
* 2 portas seguras

---

## 🔴 Difícil

* 4 monstros
* 1 porta segura
